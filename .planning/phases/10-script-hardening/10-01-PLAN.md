3. `install_nvidia_driver` -- guard: `nvidia-smi &>/dev/null` (per D-09). Body: blacklist nouveau, dracut --force, modprobe -r nouveau (with `|| true`), wget driver to /tmp/NVIDIA-driver.run using `$NVIDIA_DRIVER_URL`, chmod +x, sudo sh with --dkms --no-x-check --no-nouveau-check --ui=none --no-questions, rm the installer.
4. `generate_nvidia_cdi` -- guard: `test -f /etc/cdi/nvidia.yaml`. Body: `sudo nvidia-ctk cdi generate --output=/etc/cdi/nvidia.yaml`.
5. `mount_nfs_cache` -- guard: `mountpoint -q "$NFS_MOUNT_POINT"` (per D-06). Body: `mkdir -p "$NFS_MOUNT_POINT"`, then `timeout --kill-after=5 30 mount -t nfs -o vers=3,soft,timeo=100,retrans=2 "$NFS_SERVER" "$NFS_MOUNT_POINT"` (per D-05, SCRIPT-03).

Main block: six `step` calls in order: `step nvidia_repo install_nvidia_repo`, `step system_update run_system_update`, `step nvidia_driver install_nvidia_driver`, `step nvidia_cdi generate_nvidia_cdi`, `step nfs_mount mount_nfs_cache`, `step firewall configure_firewall`. End with `echo "Setup complete"`.

Avoid: no `eval`, no testing `$?` after commands under set -e, no quoting issues with `${EXTRA_ARGS:-}`. Use `"$@"` inside step wrapper (quoted). Use `-q` flag on wget (quiet mode).
