<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env vars -> podman run | Env var values passed as container environment; controls model path, port binding |
| host -> container | Host-side script builds and runs container with GPU access and NFS volume mount |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05 | Tampering | Container image build | accept | Image built locally from Containerfile in same directory; no remote registry pull for the wrapper layer. Base image `vllm/vllm-openai` is from official vLLM project. |
| T-10-06 | Elevation | --device nvidia.com/gpu=all | accept | GPU passthrough required for inference; container runs on internal lab servers only. |
| T-10-07 | Tampering | Volume mount /srv/hf-cache | accept | Read-only mount (`:ro`); NFS share is on internal network. No write access from container. |
| T-10-08 | Denial of Service | Port binding VLLM_PORT | accept | Internal network only; operator controls port via env var. Default 8000. |
</threat_model>
