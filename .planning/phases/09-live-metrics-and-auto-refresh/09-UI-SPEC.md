## Spacing Scale

Simple.css manages all layout spacing. Custom spacing applies only to the badge and new UI elements.

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Badge vertical padding, inline gaps |
| sm | 8px | Badge horizontal padding |
| md | 16px | Default element spacing (simple.css default) |

Exceptions: none. All new elements inherit simple.css table cell padding. No custom spacing beyond badge padding (already established in Phase 8).

## Typography

Simple.css provides the typographic scale. Phase 9 adds two text elements that use existing roles.

| Role | Size | Weight | Line Height | Phase 9 Usage |
|------|------|--------|-------------|---------------|
| Body | 16px (1rem) | 400 | 1.5 | Table cell text, "Requests" column values |
| Label | 14px (0.875rem) | 600 | 1 | Badge text (existing), "Last updated" timestamp |
| Heading | inherited from simple.css h1 | 600 | 1.2 | Page heading (existing, unchanged) |

The "Last updated" timestamp and the poll failure warning both use 14px/0.875rem at weight 400. The timestamp is secondary text; the warning is styled with color (see Color section).

## Color

Simple.css provides the dominant surface and text colors. Phase 9 does not introduce new brand colors.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg)` (simple.css white/dark) | Page background, table background |
| Secondary (30%) | `var(--accent-bg)` (simple.css) | Table header, alternating rows (simple.css handles this) |
| Accent (10%) | `#16a34a` (green) | Healthy/closed badges only (existing) |
| Destructive | `#dc2626` (red) | Unhealthy/open badges only (existing) |
| Warning | `#ca8a04` (yellow/amber) | Draining/half-open badges (existing), poll failure warning text |
| Muted text | `var(--text-light)` (simple.css) | "Last updated" timestamp |

Accent reserved for: status badges (healthy, unhealthy, draining) and circuit breaker badges (closed, open, half_open) -- unchanged from Phase 8.

### New Color Usage in Phase 9

| Element | Color | Rationale |
|---------|-------|-----------|
| "Requests" column values | Default text color (`var(--text)`) | Numeric data, no emphasis needed |
| "Last updated: HH:MM:SS" | `var(--text-light)` (simple.css muted) | Secondary information, should not compete with table data |
| Poll failure warning | `#ca8a04` (amber) | Reuses existing warning color from badge palette; subtle but visible |

## Interaction Contract

### Auto-Refresh Polling

| Property | Value | Source |
|----------|-------|--------|
| Mechanism | `setInterval` calling `refreshDashboard()` | D-03, RESEARCH.md |
| Default interval | 10 seconds | D-04 (CONTEXT.md) |
| Configuration | `INFERENCE_PROXY_DASHBOARD__POLL_INTERVAL` env var | D-03 (CONTEXT.md) |
| Parallel fetches | `Promise.all([fetch("/admin/nodes"), fetch("/admin/metrics")])` | D-05 (CONTEXT.md) |
| Start trigger | `DOMContentLoaded` -- initial call + `setInterval` | RESEARCH.md Pattern 1 |

### State Transitions

| State | Visual | Behavior |
|-------|--------|----------|
| Initial load | "Loading node data..." in table body (existing) | First `refreshDashboard()` call on page load |
| Data loaded | Table populated, "Last updated: HH:MM:SS" shown | Timestamp updates to current time |
| Poll success | Table re-rendered with fresh data | Timestamp updates, warning cleared if present |
| Poll failure | Table retains last successful data | Warning "Update failed -- retrying..." appears. Clears on next success. |
| No nodes | "No nodes registered" in table body | Timestamp still updates (poll succeeded, just empty data) |

### "Last updated" Placement

Position: Below the table, above the footer. Rendered as a `<p>` element with muted text styling. Rationale: keeps the header clean for the node count; placing near the table makes the staleness indicator contextually relevant.

### Poll Failure Warning Placement

Position: Inline with or directly below the "Last updated" text. Same `<p>` element or adjacent sibling. Styled with amber color (`#ca8a04`). Disappears on next successful poll.
