|----------|-------------|
| gateway -> remote host (SSH) | LLMFitRunner calls SSHClient.run() to execute commands on remote servers |
| remote host -> gateway (stdout) | llmfit JSON output is untrusted external input parsed by Pydantic |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | Tampering | llmfit JSON output | mitigate | Pydantic model_validate with frozen=True and extra="ignore" rejects type mismatches, drops unknown fields |
| T-25-02 | Tampering | SSH command | accept | Command is hardcoded class constant, no user input interpolated |
| T-25-03 | Denial of Service | SSH hang | mitigate | asyncio.wait_for with 60s timeout per D-02 |
| T-25-04 | Information Disclosure | LLMFitParseError.raw_output | accept | Contains hardware specs, not secrets. Phase 27 sets exposure policy |
</threat_model>
