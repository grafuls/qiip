<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSH command output | nvidia-smi and df output parsed from remote host stdout |
| etcd state writes | Provisioning state and PROVISIONING node registration |
| TCP port probe | asyncio.open_connection to remote port 22 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04 | Tampering | hostname in preflight() | mitigate | hostname is passed to asyncio.open_connection() and SSHClient.run_streaming() which validate format. Not interpolated into shell commands. Shell commands are hardcoded strings ("nvidia-smi ...", "df ..."), hostname is only the SSH target. |
| T-12-05 | Tampering | nvidia-smi/df output parsing | accept | Output from trusted internal hosts. Parsing extracts line count (GPU) and integer value (disk KB). Malformed output would cause int() ValueError caught by the SSHConnectionError/RemoteCommandError handler, adding a failure to the collect-all list. |
| T-12-06 | Denial of Service | TCP probe hanging | mitigate | asyncio.wait_for with timeout prevents indefinite hang. Timeout value from settings (default 10s). |
| T-12-07 | Information Disclosure | PreflightError.failures | accept | Contains diagnostic info (GPU names, disk space, SSH errors). Internal network only, shown to operators. No PII. |
| T-12-08 | Spoofing | PROVISIONING status in etcd | accept | Internal network, etcd access trusted. A malicious actor with etcd access could set any node to PROVISIONING to disable health checks for that node. Acceptable risk for internal lab infrastructure. |
</threat_model>
