<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Admin API | Operator sends hostname and node_id in requests |
| Admin API -> NodeProvisioner | API delegates to background provisioning/teardown |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-04 | Tampering | POST /admin/nodes/setup hostname field | mitigate | Pydantic validates hostname as str. SSHClient uses hostname only as asyncssh connection target, never interpolated into shell commands. |
| T-13-05 | Tampering | DELETE /admin/nodes/{node_id} path param | mitigate | Node existence validated against registry before teardown. Unknown node_id returns 404. |
| T-13-06 | Elevation of Privilege | Admin endpoints accessible without auth | accept | Internal network only per CLAUDE.md constraint. No auth in v1. Future: add admin authentication. |
| T-13-07 | Denial of Service | Repeated POST /admin/nodes/setup for same host | accept | Overwrites previous /provisioning/{hostname} state per D-07. Does not accumulate unbounded state. |
| T-13-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan. |
</threat_model>
