## Interaction Contract

### System Prompt Toggle

1. User clicks "System Prompt" button in model selector bar
2. Chevron rotates 180deg (points up when expanded, down when collapsed)
3. Panel slides open below model selector bar (max-height transition)
4. `aria-expanded` toggles between "false" and "true"
5. Clicking again collapses the panel

### System Prompt Persistence

1. On textarea `input` event: save value to `localStorage.setItem('systemPrompt', value)` (D-04)
2. On page load: read `localStorage.getItem('systemPrompt')` and populate textarea (D-04)
3. On send message: if system prompt is non-empty, prepend `{role: "system", content: systemPrompt}` as first element of messages array sent to `/v1/chat/completions` (CFG-01)
4. Changing system prompt mid-conversation does NOT clear messages or show confirmation (D-05)

### States

| State | Visual |
|-------|--------|
| Panel collapsed (default) | Panel hidden, chevron points down |
| Panel expanded | Panel visible with textarea, chevron points up |
| Textarea empty | Placeholder text visible |
| Textarea filled | User text visible, saved to localStorage on each keystroke |

## Accessibility Checklist

| Requirement | Implementation |
|-------------|---------------|

| Reduced motion | Transition on panel uses `prefers-reduced-motion: reduce` to disable animation |
