<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gateway -> Remote Host (SSH) | Gateway executes scripts on remote host; output is semi-trusted |
| Gateway -> Remote Host (HTTP) | Gateway polls /health endpoint; response is semi-trusted |
| Gateway -> etcd (HTTP) | Gateway writes registration data; etcd is trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Spoofing | SSH known_hosts=None | accept | D-03: lab servers reimaged frequently, internal network only. Accepted risk. |
| T-11-02 | Tampering | Command injection via hostname | mitigate | Hostname passed to asyncssh.connect() as network address (not shell-interpolated). Script paths are hardcoded constants in provisioner, not derived from user input. |
| T-11-04 | Tampering | Step marker injection from stdout | mitigate | STEP_PATTERN uses strict regex r"\[STEP:(\w+):(START|OK|FAIL)\]" — only word chars and three fixed status values. Parsed values used for logging only, never executed. |
| T-11-05 | Denial of Service | Health poll infinite loop | mitigate | Hard deadline via health_poll_timeout (default 600s). ProvisioningError raised on timeout. |
| T-11-06 | Information Disclosure | Model name from stdout | accept | Model names are not sensitive. Logged at info level for operational visibility. |
</threat_model>
