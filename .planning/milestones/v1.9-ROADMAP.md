# Milestone v1.9: Model Selection in Node Setup

**Status:** SHIPPED 2026-07-29
**Phases:** 35
**Total Plans:** 1

## Overview

Model selector dropdown on the node detail page so operators choose which downloaded model to deploy when setting up a node. Populated from the NFS model catalog API. Setup blocked when no models downloaded.

## Phases

### Phase 35: Model Selector on Node Detail Page

**Goal**: Operators select a downloaded model from a dropdown on the node detail page before setting up a node
**Depends on**: Nothing (catalog API and SetupRequest.model exist)
**Requirements**: MDL-01, MDL-02, MDL-03
**Plans**: 1 plan

Plans:

- [x] 35-01: Model selector card and catalog wiring

**Details:**
- "Setup Configuration" card between Node Info and Model Recommendations
- Native `<select>` populated from GET /admin/models/catalog on page load
- setup and retry actions include selected model in POST body
- Empty catalog: "No models downloaded" message, Setup disabled in Actions dropdown
- First model pre-selected when catalog has entries

## Key Accomplishments

1. **Model selector dropdown** — Operators pick from downloaded models before setup
2. **Catalog integration** — Dropdown populated from NFS model catalog API on page load
3. **Safety guard** — Setup blocked when no models are downloaded
4. **Zero backend changes** — Wired into existing SetupRequest.model and catalog API
