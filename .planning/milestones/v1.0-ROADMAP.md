# Milestone v1.0: MVP

**Status:** SHIPPED 2026-06-25
**Phases:** 1-6
**Total Plans:** 13

## Overview

Deliver an OpenAI-compatible gateway that proxies inference requests to vLLM nodes discovered via etcd, with least-connections load balancing, automatic failover, and SSE streaming.

## Milestone Summary

**Key Decisions:**

- FastAPI for gateway (validated — async support, OpenAI compatibility, team familiarity)
- etcd3gw for service discovery (HTTP gateway, no grpcio dependency)
- Least-connections load balancing (better utilization for variable-length inference)
- Circuit breaker pattern (trip after 3 consecutive failures, auto-recover on health check)
- BaseHTTPMiddleware for request logging (accepted trade-off with streaming duration measurement)
- hatchling as build backend (makes inference_proxy importable via uv run)
- structlog with console/JSON dual mode for logging

**Issues Resolved:**

- etcd client selection resolved in favor of etcd3gw (maintained by OpenStack)
- Middleware ordering for logging (LIFO stack: logging outer, shutdown inner)
- Target node tracking via request.state for cross-layer data passing

**Issues Deferred:**

- Human verification against live vLLM backends (Phases 3 and 6)

**Technical Debt Incurred:**

- get_settings() called as plain function in route handlers, bypassing DI
- _select_error returns misleading message for model=None + all-unhealthy scenario
- Direct _registry access in node_selector violates encapsulation (6 locations)
