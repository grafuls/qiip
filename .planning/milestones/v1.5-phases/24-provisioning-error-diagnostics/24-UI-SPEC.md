### 1. Failed State Badge (existing -- no changes needed)

Already implemented as `.badge-failed` in `dashboard.css` line 318.
Renders in the State column for nodes with `state === "failed"`.

### 2. Expandable Error Sub-Row (new)

**Location:** Inserted as a `<tr>` immediately after a failed node's row in `#node-table-body`.

**Structure:**
```
<tr class="error-subrow" style="display: none;">
  <td colspan="7">
    <div class="error-detail">
      <span class="badge badge-failed">failed at {step_name}</span>
      <pre class="error-message">{full_error_text}</pre>
    </div>
  </td>
</tr>
```

**Interaction contract (from D-06, D-07):**
- Sub-row starts hidden (`display: none`)
- Clicking the failed badge in the parent row toggles the sub-row visibility
- Failed badge gets `cursor: pointer` to signal clickability
- Toggle is per-node -- expanding one does not collapse others
- No animation required (respects `prefers-reduced-motion` pattern already in CSS)

**CSS contract for new classes:**

| Class | Properties |
|-------|------------|
| `.error-subrow` | No hover highlight (override `tbody tr:hover`). Border-bottom matches table rows. |
| `.error-subrow td` | Padding: 0 0.75rem 0.75rem 0.75rem. No top padding (visually attached to parent row). |
| `.error-detail` | Background: var(--danger-bg). Border-radius: var(--radius). Padding: 0.75rem 1rem. |
| `.error-message` | Font-family: IBM Plex Mono. Font-size: 0.8125rem. Color: var(--text). White-space: pre-wrap. Word-break: break-word. Margin: 0.5rem 0 0 0. Max-height: none (no truncation per D-08). |
| `.badge-failed[data-expandable]` | cursor: pointer (only on fleet table badges that have sub-rows). |

**JS contract:**
- In `refreshDashboard()`, after appending a failed node's `<tr>`, append an `.error-subrow` `<tr>` if `node.failed_step` or `node.error` exists
- Attach click handler on the failed badge that toggles `sub-row.style.display` between `none` and `table-row`
- Use existing `node.failed_step` and `node.error` fields from `AdminNodeResponse` JSON

## Accessibility Contract

- Failed badge with sub-row: add `role="button"`, `tabindex="0"`, `aria-expanded="false"/"true"` to indicate expandable state
- Sub-row toggle must work with Enter and Space keys (not just click)
- Error message `<pre>` block: ensure sufficient color contrast (var(--text) on var(--danger-bg) passes WCAG AA)
- Existing `prefers-reduced-motion` media query in `dashboard.css` already disables transitions
