## Interaction Contract

### Message Send Flow
1. User types in textarea, presses Enter or clicks Send
2. Enter submits, Shift+Enter inserts newline (from REQUIREMENTS.md future requirements -- pull forward since it is trivial)
3. User message appears immediately as right-aligned bubble
4. Send button transitions to disabled state (opacity 0.5, cursor not-allowed)
5. Assistant bubble appears left-aligned with streaming cursor
6. Tokens append to assistant bubble content in real time
7. On stream complete: send button re-enables, cursor removed
8. On stream error: error text appears inside assistant bubble, send button re-enables

### Smart Auto-Scroll (D-10)
- Chat area auto-scrolls to bottom as new tokens arrive
- If user scrolls up (scrollTop + clientHeight < scrollHeight - 40px threshold), auto-scroll pauses
- When user scrolls back to bottom (within 40px of bottom), auto-scroll resumes

### Model Selection
- Dropdown populated from `GET /v1/models`
- When no models available: dropdown shows "No models available", send button disabled
- On model switch: conversation stays visible, next message routes to new model

### Streaming Implementation (D-11)
- `fetch()` POST to `/v1/chat/completions` with `stream: true`
- Read response body via `ReadableStream` + `TextDecoder`
- Parse SSE `data:` lines, extract `choices[0].delta.content`
- Append content to assistant bubble, run through marked.js for markdown
- On `data: [DONE]`, finalize message

### Markdown Rendering (D-04)
- Assistant messages rendered through `marked.js`
- Code blocks get `background: var(--bg)`, `padding: 12px 16px`, `border-radius: var(--radius)`, `overflow-x: auto`
- Code block font: IBM Plex Mono 13px
- Inline code: `background: var(--bg)`, `padding: 2px 6px`, `border-radius: 4px`

## States

| State | Visual |
|-------|--------|
| Empty (no messages) | Centered empty state text, model selector active if models available |
| Idle (has messages) | Messages visible, send button enabled, textarea empty or with draft |
| Sending | Send button disabled (opacity 0.5), textarea disabled |
| Streaming | Assistant bubble growing with new tokens, streaming cursor visible (blinking `|`), send button disabled |
| Stream complete | Send button re-enabled, cursor removed, full message visible |
| Stream error | Error text in assistant bubble (red, `var(--danger)`), send button re-enabled |
| No models | Model dropdown shows "No models available", send button permanently disabled |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Keyboard submit | Enter sends, Shift+Enter for newline |
| Focus management | After send, focus returns to textarea |
| Screen reader | `role="log"` on message area, `aria-live="polite"` for new messages |
| Disabled states | `aria-disabled="true"` + `disabled` attribute on send button |
| Color contrast | All text meets WCAG 2.1 AA (existing vars already pass -- verified in dashboard) |
| Reduced motion | Respect `prefers-reduced-motion` for streaming cursor animation (match existing dashboard pattern) |
